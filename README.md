# Thirty Before Thirty

A personal website for tracking goals, milestones, and adventures before turning 30. Created to learn how to create websites. 
Live site: https://taongasamazing.github.io/thirtybeforethirty/

## Files

- `index.html` — page structure and header and footer content
- `goals.js` the list of all my goal and where to go to update the content
- `styles.css` — layout, colors, and responsive styling
- `script.js` — interactions and dynamic behavior
- `README.md` — project notes

## Update the goals

- Open `goals.js` and edit the array of goals.
- Change the title, description, status, and category text for the goal.
- Save the file and commit the changes with this command: 
git add
git commit -m "WHAT HAS CHANGED"
git push origin main.

## View locally

Open `index.html` in a browser, or run a simple local static server from the project folder.
